# MediaCollector Screenshotter 📸

[![GitHub release](https://img.shields.io/github/v/release/MediaCollector/MediaCollector-Screenshotter?style=flat-square)](https://github.com/MediaCollector/MediaCollector-Screenshotter/releases)
[![License](https://img.shields.io/badge/license-MIT-blue.svg?style=flat-square)](LICENSE)

MediaCollector Screenshotter is a specialized utility designed to capture, organize, and archive screenshots from media applications. Whether you are cataloging video search results, archiving UI layouts, or saving media metadata, this tool streamlines the process of capturing and storing your media-related screenshots.

## ✨ Features

*   **Automated Captures:** Easily capture high-quality screenshots of media applications.
*   **Media Cataloging:** Designed specifically to help archive media metadata and visual search results.
*   **Easy Integration:** Simple to set up and run alongside your favorite media apps (like notPipe).
*   **Custom Naming:** Automatically generates timestamped filenames to prevent overwrites and keep your gallery organized.
